⚠️ PHISHING ALERT: Fraudulent Emails Targeting State Vendors
Scammers are impersonating Louisiana state employees using fraudulent email addresses ending in @la-gov.us instead of the legitimate @la.gov. These emails falsely claim vendors owe fees for noncompliance with digitization standards.

Do not click links, open attachments, or submit payments. If you have already made a payment, contact your bank immediately. Verify suspicious emails directly with your established state agency contact using known contact information.

Website Disclaimer

The Louisiana Administrative Code is the state-certified publication that provides a set of rules which have been formally adopted or amended by state agencies through promulgation in the Louisiana Register. Rules are compiled according to topic and are arranged in a codified format (titles, parts, sections, etc.) so that new or amended rules can be easily referenced and researched.

The compiled rules in the Louisiana Administrative Code are published in accordance with legislative authority (R.S. 49:953 et seq.) and through legislated rulemaking procedure.

Titles of the Louisiana Administrative Code are current through the last amended date of publication. Upon promulgation in the Louisiana Register, rules are incorporated into the Louisiana Administrative Code. The last amended date refers to the latest promulgated portion of the specified LAC Title.

Contact Forest Hodges, Louisiana Administrative Code editor, for certified copies of pages contained in volumes listed below.
